# 📊 Santander Bootcamp Universia - Primeiros Passos em Power BI

Este repositório reúne os projetos, desafios e estudos desenvolvidos durante o curso Santander Bootcamp Universia - Primeiros Passos em Power BI, oferecido pela Digital Innovation One (DIO).

O objetivo deste espaço é documentar minha jornada de aprendizagem em Power BI, consolidando conhecimentos em importação, tratamento, transformação e visualização de dados por meio da criação de dashboards interativos.
