# 🚀 Desafio 01 - Analisando Dados de um Dashboard de Vendas no Power BI

## Descrição

Este projeto foi desenvolvido como parte do desafio prático do curso **Santander Bootcamp Universia - Primeiros Passos em Power BI**, oferecido pela **Digital Innovation One (DIO)**.

O objetivo do desafio foi recriar relatórios apresentados durante as aulas e desenvolver uma nova página de análise utilizando recursos de visualização do Power BI.


## Objetivos do Desafio

- Importar e analisar os dados da base Financial Sample;
- Explorar recursos de visualização do Power BI;
- Criar dashboards interativos para análise de vendas;
- Organizar informações de maneira clara e objetiva;
- Desenvolver uma página adicional com visuais definidos pelo desafio.


## Páginas Desenvolvidas

### Página 1 - Análise de Vendas por Produtos e Segmento

Contém visualizações para análise da participação das vendas por produto, preço médio dos produtos e evolução das vendas por segmento ao longo do tempo.

### Página 2 - Análise de Vendas e Lucratividade por País

Apresenta indicadores de vendas totais, total de unidades vendidas, distribuição do lucro por país, evolução mensal do lucro e vendas totais por país.

### Página 3 - Análise Geográfica de Vendas e Lucro

Página desenvolvida como proposta do desafio contendo:

- Mapa de vendas e unidades vendidas por país;
- Mapa de lucro por país;
- Gráfico de pizza com distribuição do lucro por segmento;
- Ajustes de layout, títulos e tooltips para melhorar a interpretação dos dados.
